# Pipit starter

Plan the next CLI batch from child exit codes and a failure allowance.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Pipit** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
3
2
1
3
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/pipit) · [View the release](https://github.com/Rahulchaube1/blyx-pipit/releases/tag/v0.1.0)
